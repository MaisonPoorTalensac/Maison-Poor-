# Maison Poor Talensac — V4

Version statique responsive du site Maison Poor, pensée pour être publiée directement sur GitHub Pages.

## Structure
- `index.html` : page principale
- `style.css` : design responsive
- `assets/` : vos photos utilisées dans la maquette

## Mise en ligne sur GitHub
1. Créez un dépôt, par exemple `maison-poor-v4`.
2. Envoyez `index.html`, `style.css` et le dossier `assets`.
3. Dans GitHub : **Settings → Pages → Deploy from a branch → main → / (root)**.
4. Enregistrez. GitHub Pages donnera l'adresse publique du site.

## À remplacer ensuite
- Les liens Contact / Mentions légales / CGV.
- Le téléphone et l'e-mail.
- Les zones et jours de livraison selon les règles définitives.
- Les prix et produits.
- Les icônes temporaires du header/logo si vous avez les fichiers SVG définitifs.
